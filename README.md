# iceland-mainline

Mainline Linux for the OnePlus Pad 4 (`iceland`, model OPD2514, Qualcomm SM8850P). The project's tablet runs
**Arch Linux ARM** with **KDE Plasma 6.8** on Wayland, **Plasma Login Manager** and **plasma-keyboard** as the
on-screen keyboard, on a mainline-based kernel from the [iceland-linux](https://github.com/mzakamin-hub/iceland-linux)
patch queue. The tablet's own boot loader (ABL) stays in place; our U-Boot in `boot_b` starts GRUB, and GRUB starts
the kernel.

This repository is the hub: the guide below, the list of working features, the Arch Linux ARM packaging
(`packaging/arch`) and the firmware manifest. The kernel, U-Boot, the firmware package, the VMs and DexHid have their
own repositories ([Repositories](#repositories)).

> **Fedora is no longer maintained here.** Until 26 Nov 2026 the project installed Fedora (image, RPM packages,
> install guides, the Windows installer, the dual-boot tools). That material is removed from `main`; it stays in the
> git history and in the old releases of this repository.

## Status

105 features work on the tablet. The headline:

- **Display and input:** the native 3392 x 2400 panel (dual DSI + DSC) at 30-144 Hz, backlight with automatic
  brightness, touch, pen, auto-rotate, the keyboard covers, power and volume keys, Night Light.
- **Graphics:** Adreno 840 with Mesa 26.3 (OpenGL 4.6 / ES 3.2, Vulkan 1.4 through turnip); hardware video decode
  (H.264, HEVC, VP9, AV1) and encode (H.264, HEVC).
- **Audio:** all six speakers in stereo behind a protection filter, both microphones with echo cancellation,
  headphones and DisplayPort audio.
- **Connectivity:** Wi-Fi 2.4 / 5 GHz, Bluetooth with the tablet's own address, USB host and device mode,
  DisplayPort over USB-C.
- **Power:** charging at stock's limits, the 80 / 85 % charge limit, bypass charging, the battery guard, stock's
  thermal policy, Power Saver / Balanced / Performance, suspend (s2idle) with about 0.35 %/h overnight, sleep on
  cover close.
- **Sensors and cameras:** accelerometer, gyroscope, compass, light and proximity through the sensor hub; the 13 MP
  rear and 8 MP front cameras through libcamera.
- **Apps and extras:** Android apps through DroidLoom under KWin, protected Gunyah VMs, DexHid (the tablet as
  touchpad and keyboard).

The full list is [docs/FEATURES.md](docs/FEATURES.md); the tracker with every state is
[docs/features/feature-matrix.html](docs/features/feature-matrix.html). Both are generated by
`docs/features/build.py` from `docs/features/features-data.py`.

**Not working yet:** SuperVOOC fast charging, camera autofocus, the amplifiers' own DSP protection, waking when the
cover opens, Wake-on-WLAN, the modem, NFC, fingerprint and haptics.

## Guide

### 1. Install on a Pad 4

> Read the whole section first. A write to one of the partitions listed under "Never written" can make the tablet
> unrecoverable: there is no public emergency loader for it.

**What you need.**

- A Pad 4 whose boot loader is **already unlocked** (unlocking erases the tablet; this project gives no unlock
  steps). The orange warning at boot is expected.
- Stock firmware **11.A.38** on both slots (the release the port is based on). Never flash an older firmware: it
  trips anti-rollback.
- Battery above 60 %, the PC on mains power, Android platform tools (`adb`, `fastboot`) and a known-good USB-C cable.
- Your own backups of the tablet's partitions, made before any write and kept private (they hold the unit's
  calibration and identity).

**RAM boot first.** `fastboot boot` runs an image from RAM: nothing is written and a reboot returns the tablet to
its installed state. Every image is RAM-booted before it is written anywhere. Reach the boot loader's fastboot by
holding **Volume Down** while powering on (or **Volume Down + Power** for about 15 s from a running system), then:

```bash
fastboot getvar product                 # canoe = the tablet's own boot loader (ABL)
fastboot boot u-boot-iceland-v7.img     # the plain U-Boot build, RAM only
```

U-Boot comes from the [iceland-u-boot v7 release](https://github.com/mzakamin-hub/iceland-u-boot/releases/tag/v7-2026-10-17)
(`u-boot-iceland-v7.img` for RAM boot, `u-boot-iceland-v7-footered.img` for `boot_b`; check both with
`sha256sum -c SHA256SUMS`). Without a Linux disk image on the tablet it stops in its own fastboot.

**The boot chain and layout on the project's tablet.**

```
ABL (stock, never written)
 -> boot_b: U-Boot v7, power-on menu (Volume keys move, Power selects; 5 s)
     -> the Linux disk image (its own partition, or userdata): EFI system partition with shim + GRUB 2.16
         -> GRUB (BLS entries, 3 s menu) -> linux-iceland kernel + dracut initramfs + device tree
             -> btrfs subvolumes arch-root (/), arch-var (/var), arch-home (/home)
     -> BlissROM (Android, only on a dual-boot layout)
     -> the boot loader's fastboot
```

The disk image is a GPT image with three partitions: the EFI system partition (shim and GRUB), an ext4 boot file
system (`grub2/grub.cfg` reading the BLS entries in `loader/entries/`, `grub2/grubenv`, one folder of kernels per
system) and a btrfs file system with the subvolumes. The initramfs attaches the image (dracut module `90iceland`
from `iceland-device`) and mounts `arch-root`. U-Boot's menu entry for it is still labelled "Fedora".

**The install route, as the project did it.** No install image is published and the route is **not scripted for
KDE**: every step below is **manual**.

1. *Build the root file system* (manual). An Arch Linux ARM aarch64 root, made in a container on a PC from the
   official `ArchLinuxARM-aarch64-latest.tar.gz`, with: `base`, `dracut`, `btrfs-progs`, `networkmanager`, `bluez`,
   `pipewire` / `wireplumber`, `alsa-ucm-conf`, `zram-generator`, `irqbalance`, `power-profiles-daemon`, `grub` (for
   `grub-editenv` only), `plasma-meta`, `plasma-login-manager`, `plasma-keyboard`, the KDE apps you want, and the
   project's packages from `packaging/arch` ([section 2](#2-build-from-source)): `iceland-device`,
   `iceland-device-kde`, `iceland-ppd`, `iceland-coexist`, `qbootctl`, `mesa-iceland` (with the `vulkan-*-iceland`
   packages), `hexagonrpc`, `libssc`, `iio-sensor-proxy-iceland`, `libcamera-iceland`, `upower-iceland`, plus
   `iceland-firmware` and the kernel `linux-iceland`. `networkmanager-p2p` is only needed for DexHid's wireless
   display. Do not install `mkinitcpio`, `linux-aarch64`, `limine` or any other boot loader or UKI tool.
2. *Unit-specific files* (manual). The sensor hub's DSP files, the sensor calibration and the Bluetooth address
   belong to one tablet: take them read-only from your own tablet's partitions. They are never published.
3. *The disk image* (manual). The project's image comes from its earlier Fedora image: the EFI system partition with
   shim and GRUB 2.16 and the ext4 boot file system were kept, and the Arch root was unpacked into the btrfs
   subvolumes. A new image needs the same three partitions; there is no tested recipe yet for making one from
   scratch.
4. *The kernel entry.* Installing `linux-iceland` with `iceland-coexist` present writes the kernel, its initramfs and
   device tree into the boot file system and a new BLS entry; it never changes the default entry.
5. *Test tethered.* Write the image to the partition that holds it, then RAM-boot U-Boot (`fastboot boot
   u-boot-iceland-v7.img`) until the system reaches the Plasma Login Manager reliably. `iceland-device-kde` does not
   enable the greeter by itself: `sudo systemctl enable plasmalogin.service` (and disable any other display manager).
6. *Write U-Boot to `boot_b`*, only after step 5 works, and only with a saved copy of your current `boot_b`. The
   footered image's AVB footer must fit your tablet's `boot_b`; flashing `boot_b` resets slot b's retry count until
   `iceland-slot-mark` marks the slot successful after a good boot.

**Never written** by anything in this project: the boot firmware (`xbl*`, `abl*`, `tz*`, `hyp*`, `aop*`, `uefi*`,
`soccp*` and the rest of the chain), the radio and DSP partitions (`modem*`, `bluetooth*`, `dsp*`), the per-device
data (`persist`, `cdt`, `ddr`, `dinfo`), the security state (`devinfo`, `keystore`, `frp`, `secdata`,
`uefivarstore`), the partition tables and the UFS firmware. Never `fastboot -w`, `flashall`, `erase`, `format`,
`set_active` or `flashing lock`; never switch the active slot. Inside Linux, `iceland-device` keeps the other
internal partitions read-only.

### 2. Build from source

**Kernel.** The patch queue, its build scripts and its config are in
[iceland-linux](https://github.com/mzakamin-hub/iceland-linux); the newest release is tag
[q91n](https://github.com/mzakamin-hub/iceland-linux/releases/tag/q91n) (`7.4.0-rc1-iceland-00743`, the queue on Linux
`v7.4-rc1`; its release files are Fedora RPMs). The project's tablet runs a newer 7.4.0-rc4 build of the queue that is
not released yet, and the `linux-iceland` PKGBUILD is not published yet: build the kernel with that repository's
scripts (see its README) and package it yourself.

**Packages.** Build `packaging/arch/*` in an Arch Linux ARM aarch64 environment. On an x86 PC a container works,
for example rootless podman with qemu-user-static registered for aarch64:

```bash
podman import --arch arm64 --change 'CMD ["/bin/bash"]' ArchLinuxARM-aarch64-latest.tar.gz localhost/alarm:base
podman run --rm -it --arch arm64 -v "$PWD":/src localhost/alarm:base
# inside the container, once:
#   under qemu-user: comment out CheckSpace and add DisableSandbox under [options] in /etc/pacman.conf
#   pacman-key --init && pacman-key --populate archlinuxarm && pacman -Syu base-devel git
#   useradd -m builder   (makepkg does not run as root)
# then as that user, in each /src/packaging/arch/<package>/:  makepkg -s --sign
```

- Some sources are not in the repository (release tarballs, `iceland-device`'s tar files): each package's
  `SOURCES-NOT-STAGED.txt` lists them with size and sha256, `iceland-device/MAKE-TARS.txt` says how to make the
  three tar files.
- Sign with **your own** key (`makepkg --sign`, `GPGKEY` in `makepkg.conf`) and make a signed repository:
  `repo-add -s -v iceland-local.db.tar.zst *.pkg.tar.zst`.
- `iceland-firmware` is in its own repository ([iceland-firmware](https://github.com/mzakamin-hub/iceland-firmware),
  every file sha256-pinned; its published package is an RPM).

**U-Boot.** [iceland-u-boot](https://github.com/mzakamin-hub/iceland-u-boot) holds the U-Boot tree for the tablet,
the install build with its boot menu and the build scripts (see its README). The AVB footer for `boot_b` is made for
your own tablet.

### 3. Daily use and updates

**Updates.** `sudo pacman -Syu`, as on any Arch Linux ARM system. The project does not publish a binary Arch
repository: the project's packages come from your own signed repository, listed first in `/etc/pacman.conf`:

```ini
[iceland-local]
SigLevel = Required
Server = file:///var/lib/iceland/repo/aarch64
```

Import your signing key once (`sudo pacman-key --add` with your public key file, then `sudo pacman-key --lsign-key`
with its id). The project's tablet keeps `IgnorePkg = linux-firmware-qcom linux-firmware-atheros grub` (the firmware
comes from `iceland-firmware`; the GRUB that boots is the one in the EFI system partition). Never run `grub-install`
or `grub-mkconfig`.

**New kernels.** A new `linux-iceland` package gets its own GRUB entry next to the running one; the default stays.
Try it once with `sudo iceland-oneshot arm <name> --entry <entry id>` and reboot (the boot after that one uses the
default again). To make it the default: `sudo grub-editenv /boot/grub2/grubenv set saved_entry=<entry id>`; the entry
ids are the file names in `/boot/loader/entries/` without `.conf`. GRUB's menu shows for 3 s at every start: Volume
keys move, Power boots.

**Power.** Plasma's power profile switch (or `powerprofilesctl set power-saver|balanced|performance`) selects the
tablet's stock-limited profiles from `iceland-ppd`; `iceland-thermal` caps every profile. Closing a keyboard cover
suspends the tablet within about a second; the power key wakes it. The charge limit (80 / 85 %) is in Plasma's power
settings; `iceland-bypass status|on|off` controls bypass charging.

**Auto-rotate.** KDE rotates only in tablet mode by default. With a keyboard case attached, untick "Only when in
tablet mode" in System Settings > Display Configuration to keep auto-rotate.

**Android apps (DroidLoom).** DroidLoom comes from its upstream pacman repository `[droidloom]` (listed last in
`pacman.conf`) and updates with `pacman -Syu`. `sudo iceland-droidloom-pacman plan` is an optional check that shows
what an update would take from `[droidloom]` before you run it.

**Snapshots and rollback.** Before every pacman transaction `iceland-device` takes a read-only btrfs snapshot of
`arch-root` (the newest 3 are kept; `/var` and `/home` are not snapshotted). List them with
`sudo /usr/libexec/iceland/iceland-snapshot list`; `sudo /usr/libexec/iceland/iceland-snapshot rollback <name>` makes
one the root from the next boot on (the old root is kept). A rollback has not been exercised on the Arch layout yet.

**Recovery.** If a new kernel does not start, pick the previous entry in GRUB's menu. If nothing on the tablet
starts, hold Volume Down at power-on to reach ABL's fastboot and RAM-boot a known-good image with `fastboot boot`;
nothing is written. A ready-made rescue image is not published.

**VMs and DexHid.** Protected Gunyah VMs with the Virtual Machines app:
[iceland-gvm](https://github.com/mzakamin-hub/iceland-gvm) and [iceland-vms](https://github.com/mzakamin-hub/iceland-vms)
(their releases are RPMs; the Arch packages the tablet uses are not published yet). DexHid (the tablet as touchpad
and keyboard for a USB-C monitor, or as USB keyboard and mouse for another computer):
[DexHid](https://github.com/mzakamin-hub/DexHid).

| `firmware/` | the firmware manifest: which stock file goes where under `/lib/firmware` |
| `.github/` | CI: `checks.yml` (feature matrix up to date, syntax, PKGBUILD sources, shellcheck) and `privacy.yml` (privacy scan of the files and commit messages) |

Before a pull request run `python3 docs/features/build.py`, `python3 .github/scripts/package-checks.py` and
`python3 .github/scripts/privacy-scan.py` from the repository root; each must pass.

**Issues.** Open them in the repository the problem concerns: this one for packaging and the guide,
[iceland-linux](https://github.com/mzakamin-hub/iceland-linux/issues) for the kernel,
[iceland-u-boot](https://github.com/mzakamin-hub/iceland-u-boot/issues) and
[iceland-firmware](https://github.com/mzakamin-hub/iceland-firmware/issues). Useful attachments:

```bash
uname -r
pacman -Q | grep -E 'iceland|mesa|libcamera|upower|sensor|libssc|hexagonrpc'
journalctl -b --no-pager > journal.txt
sudo dmesg > dmesg.txt
```

Read them before you attach them, and remove the tablet's serial number, MAC and Bluetooth addresses, Wi-Fi network
names, IP addresses and user names. Never attach partition backups, calibration or other files from the tablet's
partitions.
