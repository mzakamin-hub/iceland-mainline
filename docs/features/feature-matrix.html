Pad 4 feature matrix

Everything is tested by booting from RAM; nothing is installed on the tablet yet. Status as of 3 Oct 2026: the kernel queue has 188 Pad 4 patches on top of 138 SM8850 base patches (169 test runs with 94 test kernels since 28 Sep). Charging, the charge limit, low-battery limiting, thermal and GPU cooling follow stock; both cameras and GNOME Camera work; the pogo keyboard, the pen charger and every wake source are proven without hands; every value was compared with stock; deep sleep reaches CX collapse 98 % of the time. Battery life measured on the tablet (53.8-56.7 Wh, screen at 50 %): light use 14-17 hours, 1080p video 15-16 hours, all cores busy about 7 hours, screen off but awake about 3.5 days; standby is measured by a night unplugged. The install is planned (docs/INSTALL-PLAN.md); its kernel and device packages and both U-Boot builds are made; with the USB link fixed in the queue the rehearsal's build run made the whole image on the tablet in about 4 minutes, and its rehearsal boots reach the desktop: the release candidate's rehearsal r2i passed all 46 checks (nothing written). The install is rehearsed end to end: release candidate q85 + iceland-device 0.19, rehearsal r2i 46 / 0 / 0 on 3 Oct 2026; open before the install: the owner's decisions (AVB footer, the RAM probe, boot_b vs recovery_b, dual boot) and the owner-only checks.
